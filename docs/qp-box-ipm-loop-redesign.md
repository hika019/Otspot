## 2. 設計要求

- **R1 (RSS)** 線形系の次元は n + m_real を維持すること。box 行を状態変数として
  restore する案は対象外。CONT-300 で −75% 級の收益を維持できること (実測必須)。
- **R2 (自己共伴性)** box 行に関する反復は、対数 barrier
  `μ·Σ_t(−log s_t(x))` を含むスカラーポテンシャルの damping 付き Newton として
  説明できること。ポテンシャルを持たない方向に対する α クリップ
  (現行の fraction-to-boundary 単独依存) を box 行の安全機構としない。
- **R3 (機構被覆)** §3 の増幅源を代数から除去すること。クリップ・cap・床での
  抑え込み (症状隠し) は不可。dt 2-cycle (P6) には機構寄与の除去を明示すること。
- **R4 (忠実性)** s_t(x) = b_t − a_tᵀx の依存性 (box 忠実) を維持・強化すること。
  非忠実マスキング (P5) に依拠した成功は不問とする。
- **R5 (被爆半径)** 現在緑の問題 (M1 修正後 9 件緑化済み + 旧緑) の力学を、
  失敗機構が該当しない lane では変更しないこと。独立オラクル
  (`data/baseline_objectives` / clarabel 照合) での検証を必須とする
  (ソルバ自己申告をオラクルとしない)。

## 3. 崩壊機構の精密解析

### 3.1 現行 box 行代数の二重役割衝突

拡張系 (除去前) で box 行 t は係数 `a_t = ±e_j`、従属スラック `s_t(x) = b_t − a_tᵀx`、
独立乗数 y_t、補数 `s_t y_t = μ`。正確 Schur 除去後の x 対角は
`d_t = 1/σ_t = y_t/s_t` (δ_d = 0)。この 1 個の量が 2 つの役割を担う:

- **(役割 1: 原始剛性)** 壁を守る x ブロックの剛性は barrier 幾何
  `μ/s_t²` でなければならない (Dikin 計量。§3.2)。
- **(役割 2: 双修正利得)** 後退代入 `dy_t = d_t(a_tᵀdx − r_p_mod_t)` は
  補数欠損 `r_c_t = σ_c μ − s_t y_t (− ds_t dy_t)` の修復利得でもある。

中心路上 (s_t y_t = μ、すなわち y_t = μ/s_t) では両者は一致する
(`y_t/s_t = μ/s_t²`)。**off-path では衝突する**: 活性余剰 s_t ~ 1e-6、
μ ~ 1e6〜1e7 の初期域 (trio 実測) では y_t ≈ 2 のまま 12 桁 off-path で、

- 役割 1: 剛性 y_t/s_t ≪ μ/s_t² — 壁が守れない (P2 の壁面爬行が毎反復
  (1−τ) 分の余剰を合法に消費する)。
- 役割 2: 中心路復帰に必要な全修正量 `y_t → μ/s_t` (2 → 1e12 相当) を
  Newton が 1 反復で dump する: `dy_t = r_c_t/s_t ≈ σ_c μ/s_t`、x 前方散乱
  `−a_t r_c_t/s_t`。これが P3 の 1e12〜1e18 増幅の正体で、**Aᵀdy リーク**は
  この爆発した dy が `A_extᵀ dy` として停留残差と散乱右辺に還流する経路
  (Schur 形 `S = A M⁻¹Aᵀ − D` の `D⁻¹` 増幅と同源) である。

fraction-to-boundary は α をクリップするだけで、方向が「どのポテンシャルの
降下方向か」を一切保証しない。barrier ポテンシャルの Newton 方向でなければ、
壁に近づくほど補正が 1/s で自己増幅する写像になり、P2〜P4 の螺旋が成立する。

### 3.2 barrier 化すると何が変わるか (自己共伴性の定式化)

box 行を「独立 y をもつ補数行」から「従属双対をもつ対数 barrier」へ置き換える:

`y_t(x) := μ / s_t(x)` (定義)、barrier `Φ(x) = −Σ_t log s_t(x)`、
ポテンシャル `F(x) = f_PMM(x) + μ Φ(x)`。F は 1-自己共伴 (対数 barrier +
凸平滑項の和) で、壁で +∞ に発散する。F の Newton 系を線形化すると
(box 行の補数方程式は線形化する対象として存在しない):

```
dy_t = −(μ/s_t²)·ds_t = (y_t/s_t)·a_tᵀdx          … (barrier 微分)
(Q + ρI + D_b) dx + Aᵣᵀ dyᵣ = r_d                  … (D_b = diag Σ_t y_t a_t a_tᵀ = diag μ/s_t²)
Aᵣ dx − (Σᵣ + δ_d I) dyᵣ = r_p,ᵣ − r_c,ᵣ/yᵣ        … (実制約行は現行 PMM のまま)
```

x ブロックは現行の正確 Schur と**同一代数** (d_t = y_t/s_t) で、次元は
n + m_real のまま (R1 合格)。違いは 3 点:

1. `r_c_t ≡ 0` (構造) — 補数方程式が消えたので線形化対象が無い。
   P3 の増幅源 `σ_c μ/s_t` が右辺から**源头で消滅**する。
2. 役割 1 の剛性が定義により常に `μ/s_t²` (off-path 概念が box 行に存在しない)。
   壁パンチ方向は F の Newton 減衰量 λ を大きくして damping
   (`α ≤ 1/(1+λ)` 相当の line search) に検出される — α クリップではなく
   ポテンシャルの発散が壁を守る (R2)。
3. box 行の正味は自動: `y_t + α dy_t = y_t (s_t + α ds_t)/s_t` なので
   fraction-to-boundary `s + αds ≥ (1−τ)s > 0` が `y > 0` を含意する
   (α_y 側の検査は box 行から不要になる。現行 α_y は無害に非活性化する)。

### 3.3 dt 2-cycle の機構分解

P6(b) の壁パンチスルー/反動は §3.1 の剛性不足の小型版であり、
§3.2 の barrier 剛性で抑制される側面がある。P6(a) (PEU 符号盲目 + OR 高速減衰)
はループ外周スケジュールの欠陥で、barrier 化とは独立に存在する。本契約では
(a) を §5 の候補 C2 (最小形: 符号認識 `r = max(0, μ_k − μ_{k+1})/μ_k` と
δ 減衰の原始改善ゲート化 — 現行 box-only lane に実装済みの安全策の一般化) として
スパイク成否に応じて適用する。dt の 2-周期は trio と機構を共有しないため、
trio の修正だけでは直らないという事実 (P1 と P6 の分離) を設計要求 R3 に含める。

## 6. C1 実装契約

- **C1-1 (定義)** 除去済み box 行 t の乗数を状態変数から降格し、毎反復先頭で
  `y_t := μ / s_t(x)` を再割当する (σ_vec 組立はその後: `σ_t = s_t²/μ`)。
  初期点・warm start 経路も同一の割当で作る (補数に初期ズレを作らない)。
- **C1-2 (μ の定義)** `μ := Σ_{i∈実制約不等式行} s_i y_i / m_ineq^real`。
  box 行は定義により `s_t y_t = μ` で寄与一定のため推定量から除外する
  (分子・分母から除去済み box 行を落とす)。mu_aff・mu_new・収束判定の μ 測定は
  すべてこの定義に統一する。
- **C1-3 (右辺)** predictor/corrector/Gondzio の `r_c` に対し box 行成分を
  構造的 0 とする (`r_p_mod` box 成分は r_p ≡ 0 と併せ 0)。box 行の
  `dy_t = d_t·a_tᵀdx` は後退復元値として維持 (ray 検証器・感度出力の
  レイアウト不変。検証器は独立再検証であり契約不変)。
- **C1-4 (歩み)** 更新は x と実制約行の (s, y) を積分し、box 行は
  `fill_slacks` 後の `s_t(x)` と再定義 μ から §C1-1 を再適用
  (積分しない)。fraction-to-boundary の s 側は現行のまま (R2 より
  方向自体が減衰量で管理されるため、P2 の地図は現れないこと-success 基準に含まれる)。
- **C1-5 (lane)** barrier 化は **実制約不等式行が 1 行以上** の問題のみで有効。
  実不等式行を持たない問題 (box-only・実制約 Eq-only) は現行の力学を維持する
  — barrier-only path-following は μ を補数から推定できずスケジュール表が要る
  (古典的 `μ_{k+1} = σμ_k` 化)。緑の問題の力学を無関係な変更で壊さないための
  境界であり、box-only の barrier 化は本 PR のスコープ外 (将来課題) とする。
- **C1-6 (認証境界)** 出力双対 `bound_duals_t = y_t = μ/s_t` は barrier 路の
  極限として活性制約の正当乗数へ収束する。受理ゲート (duality/stationarity
  検証) の契約は不変。**Optimal の主張には従来どおり独立オラクル照合を要する**
  (§8)。

## 7. 検証契約 (スパイク → 実装)

スパイク (wip branch、throwaway) 成功基準 — qgfrdxpn と dt_qp の両方でトレース証拠:

- S1 α が τ クリップに張り付かない (P2 の ×(1−τ) 地図が現れない)、
- S2 ‖dx‖ が有界 (爆発の双方向振れが 1 オーダー以内)、
- S3 μ が eps 方向へ単調降下し、primal residual が 0 へ (nrp_rel ≈ 1.0 の
  ピン留めが解消)、
- S4 解が独立オラクル (data/baseline_objectives / clarabel) と一致。

スパイク失敗時: 本設計を新証拠で 1 回反復し (P6(a) 相当の証拠なら C2 最小形を
C1 に併合)、第 2 候補も失敗したら PARK (設計文書は成果物として PR に残す)。

実装 (M-C) 時の検証: sentinel (revert で fail する tests/ 側テスト、barrier 不変量
`y_t·s_t ≡ μ` と 1/s 散乱不在)、14 バッテリー + lib-only で旧緑不変、
CONT-300 アンカー (wall + ピーク RSS で R1 実測)、maros_meszaros 部分ベンチ。

## 9. スパイク実測による改訂 (2026-11-20、wip/qp88-barrier f01bdbd7)

### 9.1 実施内容と実測
C1 実装契約 (従属双対 y_t = μ/s_t、μ 推定を実不等式行から、box 行 r_c ≡ 0) を
wip ブランチに実装し、§7 の success 基準 S1–S3 を qgfrdxpn で検証した。
safeguard として (§7 反復条項の C2 最小形拡張):
μ 減少率の符号認識、δ の原始改善ゲート、μ 後退時の forced re-centering (σ=1/4)、
初期 μ₀ の余剰-commensurability 上限、ρ の独立幾何減衰を追加して各 variant の
trace を取得した (証跡 `/tmp/opencode/presolve_impl/spike_qgfrdxpn_c*.trace`)。

- **成立した予測 (dt_qp)**: dt_qp_2cycle が C1 単体で解消し Optimal、目的値 4.0
  が独立オラクル値と精确一致 (§1 ⑥2-周期の機構分解 (b) 除去は正しい)。
- **反証された予測 (trio)**: S3 不成立 — qgfrdxpn は全 variant・全 attempt で
  `nrpE ≈ 1.0` (eq 行の原始残差がデータ全スケール比で凍結) が解消しない。
  μ は符号認識 safeguard 後に発走は消えるが進捗せず (4.6 → 停滞 → 1e7 級へ
  再発散)、ρ を 8 → 3.2e-5 まで独立に減衰させても nrpE は動かない。
  S1/S2 (α 非クリップ・‖dx‖ 有界) は成立 — 失败は步長・步幅の失敗ではない。
- **退行**: barrier lane は対象外のはずの good-case にも波及し、lasso 系 3 件が
  iter 127/123/243 (予算 40)、ill-scaled 2 件が iter 236+ (予算 30) へ膨張して
  予算超過 (旧力学では ≤ 予算内)。純 barrier/全 safeguard どちらの設定でも不可。

### 9.2 真因の修正 (本契約 §3.2 の仮定の誤り)
barrier 定式化の box 行 Newton 対角は `∂²(−μ log s)/∂s² = μ/s²` であり、中心路の
定義 `y = μ/s` の下では **μ/s² ≡ y/s = Σ(鞍系 D ブロック対角)と恒等**。すなわち
C1 が「鞍系の 1/s 増幅源を除去する」という §3.2/§4 の予測 (R3 ○) は誤りで、
従属双対化は同じ増幅対角を保持したまま y の力学の自由度だけを奪う。初期点が
全 active wall に余剰 2e-6〜2e-2 (init の strict_interior_shift は ε スケール)
で位置し μ₀ が実不等式行積定型で μ₀ ≈ 70 である限り、増幅対角は μ/s² ≈ 1e14〜18
で Aᵀ 結合を介して eq 行の修復信号を埋め尽くす。実測の nrpE 凍結はこれの一意の
帰結であり、ρ・δ・步長系のどの safeguard でも回復しない (§9.1 の C4 実測)。
pre-box 旧解の収束は独立スラックの非faithful 脱出 (§2.3 の捏造プロファイル) が
同じ増幅の下で方向を誤魔化していたもので、faithful 化はその隠蔽を剥がしただけ
である。

### 9.3 改訂後決定
失敗機構は「Newton 方向が eq 修復成分を持たない (方向品質)」ことであり、
候補 (2) PMM 信頼域は步長の機構にしか作用しないため実測失败機構に無関係、
